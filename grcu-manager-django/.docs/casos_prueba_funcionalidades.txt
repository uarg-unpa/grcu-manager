CP-001: LOGIN CON GOOGLE OAUTH2 - USUARIO NUEVO
==============================================

Prioridad: Alta
Tipo: Funcional
Modulo: Autenticacion

Descripcion:
Verificar que un usuario nuevo pueda registrarse e iniciar sesion usando Google OAuth2.

Precondiciones:
- Sistema esta operativo
- Usuario tiene cuenta de Gmail valida
- OAuth2 configurado correctamente

Pasos:
1. Navegar a la pagina de login del sistema
2. Hacer clic en "Iniciar sesion con Google"
3. Seleccionar cuenta de Gmail en el popup de Google
4. Autorizar acceso a la aplicacion

Resultado Esperado:
- Usuario es creado automaticamente en el sistema
- Email, nombre y avatar se obtienen de Google
- Usuario es redirigido al dashboard correspondiente
- Se registra actividad de LOGIN en auditoria_registroactividad
- Avatar URL se almacena en campo accounts_usuario.avatar
