CP-001: INICIO DE SESION ADMINISTRADOR EXITOSO
==============================================

Prioridad: Alta
Tipo: Funcional
Modulo: Autenticacion

Descripcion:
Verificar que un usuario con rol de administrador pueda iniciar sesion correctamente en el sistema.

Precondiciones:
- Usuario administrador existe en el sistema

Resultado Esperado:
