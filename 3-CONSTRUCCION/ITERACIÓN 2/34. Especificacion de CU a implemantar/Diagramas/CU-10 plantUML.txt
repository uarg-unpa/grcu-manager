@startuml


actor "Usuario (Líder/Dev/Cliente/Admin)" as Usuario #purple
boundary InterfazUsuario
boundary PDetalleCasoDeUso
boundary PTabHistorialCU
boundary ModalDetalleHistorialCU
boundary MensajeSistema
control ManejadorCasosDeUso
control ManejadorHistorialCU
control ValidadorPermisos
database BD

== Flujo principal ==
Usuario -> InterfazUsuario: 1) Accede a lista de Casos de Uso
InterfazUsuario -> PDetalleCasoDeUso: 2-3) Selecciona "Ver detalle"
PDetalleCasoDeUso -> ManejadorCasosDeUso: Cargar datos del CU
ManejadorCasosDeUso -> BD: SELECT caso_de_uso by id
BD --> ManejadorCasosDeUso: Datos CU
ManejadorCasosDeUso --> PDetalleCasoDeUso: Render con pestañas (info, reqs, adjuntos, comentarios, historial)

Usuario -> PDetalleCasoDeUso: 5) Click pestaña "Ver Historial"
PDetalleCasoDeUso -> ManejadorHistorialCU: 6) Traer versiones del CU
ManejadorHistorialCU -> BD: SELECT * FROM historical_casodeuso
ManejadorHistorialCU -> BD: SELECT * FROM historical_detalle_trad/agil
BD --> ManejadorHistorialCU: Versiones y detalles
ManejadorHistorialCU --> PTabHistorialCU: 7) Línea de tiempo (desc) + "Ver detalles"
PTabHistorialCU --> Usuario: Mostrar timeline

Usuario -> PTabHistorialCU: 8) Click "Ver detalles"
PTabHistorialCU -> ValidadorPermisos: ¿Puede ver valores antiguos/nuevos?
ValidadorPermisos -> BD: SELECT permisos del usuario en el proyecto
BD --> ValidadorPermisos: Permitido / Limitado

alt Permiso completo
  PTabHistorialCU -> ManejadorHistorialCU: Cargar versión (o A/B)
  ManejadorHistorialCU -> BD: SELECT versión(es) solicitada(s)
  BD --> ManejadorHistorialCU: Datos
  ManejadorHistorialCU --> ModalDetalleHistorialCU: Tabla "Antes → Después"
  ModalDetalleHistorialCU --> Usuario: 9) Ver comparativa
  Usuario -> PDetalleCasoDeUso: 10) Volver al caso de uso
  Usuario -> InterfazUsuario: 11) Volver a la lista
else Permiso limitado
  PTabHistorialCU --> Usuario: Mostrar resumen sin valores antiguos/nuevos
  PTabHistorialCU -> MensajeSistema: "Permisos limitados"
end

== Alternativos ==
alt 6a) Caso de uso sin historial
  ManejadorHistorialCU -> BD: SELECT history (count=1)
  BD --> ManejadorHistorialCU: Solo creación
  ManejadorHistorialCU --> PTabHistorialCU: Mostrar entrada de creación (fecha, hora, creador)
  Usuario -> PDetalleCasoDeUso: 10) Volver al caso de uso
end

alt 6b) Historial muy extenso (>100)
  PTabHistorialCU -> ManejadorHistorialCU: Paginación y filtros avanzados
  ManejadorHistorialCU -> BD: SELECT ... LIMIT/OFFSET + filtros
  BD --> ManejadorHistorialCU: Página de resultados
  ManejadorHistorialCU --> PTabHistorialCU: Navegación + opción Exportar CSV/PDF
  note right: El CU finaliza tras exportar o volver
end

@enduml
