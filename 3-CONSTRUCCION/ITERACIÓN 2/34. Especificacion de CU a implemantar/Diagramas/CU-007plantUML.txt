@startuml
title CU07 - Priorizar requerimiento (MoSCoW)

actor "Líder del proyecto" as Lider #purple
boundary InterfazUsuario
boundary PRequerimientos
boundary PPriorizarRequerimientos
boundary MensajeSistema
control ValidadorPermisos
control ManejadorProyecto
control ManejadorRequerimientos
database BD

== Flujo principal ==
Lider -> InterfazUsuario: 1) Accede al dashboard
InterfazUsuario -> PRequerimientos: 2-3) Selecciona proyecto y va a "Requerimientos"
PRequerimientos -> PPriorizarRequerimientos: 4) Click "Priorizar requerimientos"

PPriorizarRequerimientos -> ValidadorPermisos: 5) Verificar que es líder del proyecto
ValidadorPermisos -> BD: SELECT proyecto.lider = usuario
BD --> ValidadorPermisos: OK
ValidadorPermisos --> PPriorizarRequerimientos: autorizado

PPriorizarRequerimientos -> ManejadorRequerimientos: 6) Obtener requerimientos del proyecto
ManejadorRequerimientos -> BD: SELECT * FROM requerimientos WHERE proyecto_id=...
BD --> ManejadorRequerimientos: lista de requerimientos + prioridad actual
ManejadorRequerimientos --> PPriorizarRequerimientos: 7) Mostrar tabla (código, nombre, tipo, estado, dropdown MoSCoW)

Lider -> PPriorizarRequerimientos: 8) Selecciona prioridad MoSCoW por cada requerimiento
Lider -> PPriorizarRequerimientos: 9) Click "Guardar prioridades"

PPriorizarRequerimientos -> ValidadorPermisos: 10) Revalidar permisos
ValidadorPermisos -> BD: SELECT rol
BD --> ValidadorPermisos: OK
ValidadorPermisos --> PPriorizarRequerimientos: OK

PPriorizarRequerimientos -> ManejadorRequerimientos: 11) Actualizar prioridades en BD
ManejadorRequerimientos -> BD: UPDATE requerimiento SET prioridad=... (por cada req)
BD --> ManejadorRequerimientos: OK
ManejadorRequerimientos -> BD: (opcional) INSERT auditoria_registroactividad
BD --> ManejadorRequerimientos: OK

ManejadorRequerimientos --> PPriorizarRequerimientos: 12) Confirmación
PPriorizarRequerimientos --> MensajeSistema: "Prioridades actualizadas correctamente"
PPriorizarRequerimientos -> ManejadorRequerimientos: 13) Recargar lista con nuevas prioridades
ManejadorRequerimientos -> BD: SELECT * FROM requerimientos
BD --> ManejadorRequerimientos: lista actualizada
ManejadorRequerimientos --> PPriorizarRequerimientos: Mostrar lista actualizada

== A1) Usuario no es líder ==
alt A1 - No es líder
  PPriorizarRequerimientos -> ValidadorPermisos: verificar
  ValidadorPermisos -> BD: SELECT proyecto.lider
  BD --> ValidadorPermisos: NO coincide
  ValidadorPermisos --> PPriorizarRequerimientos: no autorizado
  PPriorizarRequerimientos --> MensajeSistema: "Solo el líder puede priorizar requerimientos"
  PPriorizarRequerimientos -> InterfazUsuario: Redirigir a dashboard
end

== A2) Proyecto sin requerimientos ==
alt A2 - Lista vacía
  ManejadorRequerimientos -> BD: SELECT * FROM requerimientos WHERE proyecto_id=...
  BD --> ManejadorRequerimientos: []
  ManejadorRequerimientos --> PPriorizarRequerimientos: lista vacía
  PPriorizarRequerimientos --> MensajeSistema: "No hay requerimientos para priorizar"
  PPriorizarRequerimientos -> InterfazUsuario: Mostrar botón "Crear requerimiento"
end

== A3) Proyecto con metodología ágil ==
alt A3 - Metodología ágil
  PPriorizarRequerimientos -> ManejadorProyecto: Consultar metodología
  ManejadorProyecto -> BD: SELECT proyecto.metodologia
  BD --> ManejadorProyecto: "AGIL"
  ManejadorProyecto --> PPriorizarRequerimientos: Advertencia
  PPriorizarRequerimientos --> MensajeSistema: "La priorización MoSCoW aplica principalmente a metodología tradicional"
end

== A4) Error al guardar prioridad ==
alt A4 - Error en BD
  ManejadorRequerimientos -> BD: UPDATE ...
  BD --> ManejadorRequerimientos: Excepción
  ManejadorRequerimientos --> PPriorizarRequerimientos: rollback / no se guardó
  PPriorizarRequerimientos --> MensajeSistema: "Error al actualizar prioridades, intente nuevamente"
end

@enduml
