@startuml


actor "Usuario (Líder/Desarrollador)" as Usuario #purple
boundary InterfazUsuario
boundary PDetalleRequerimiento
boundary PRelacionarRequerimientos
boundary MensajeSistema
control ValidadorPermisos
control ManejadorDependencias
control ManejadorTrazabilidad
database BD

== Flujo principal ==
Usuario -> InterfazUsuario: 1) Accede al detalle de un requerimiento
InterfazUsuario -> PDetalleRequerimiento: Mostrar detalle
Usuario -> PDetalleRequerimiento: 2) Click "Relacionar requerimientos"

PDetalleRequerimiento -> ValidadorPermisos: Verificar permisos de edición
ValidadorPermisos -> BD: SELECT permisos(usuario, proyecto)
BD --> ValidadorPermisos: OK
ValidadorPermisos --> PDetalleRequerimiento: Autorizado

PDetalleRequerimiento -> PRelacionarRequerimientos: 3) Mostrar lista de requerimientos disponibles
PRelacionarRequerimientos -> ManejadorDependencias: Obtener lista
ManejadorDependencias -> BD: SELECT * FROM requerimientos WHERE proyecto_id=...
BD --> ManejadorDependencias: Lista de requerimientos
ManejadorDependencias --> PRelacionarRequerimientos: Mostrar lista de selección

Usuario -> PRelacionarRequerimientos: 4) Selecciona requerimientos y confirma
PRelacionarRequerimientos -> ManejadorDependencias: 5) Validar relación existente
ManejadorDependencias -> BD: SELECT * FROM dependencias WHERE req_origen=? AND req_destino=?
BD --> ManejadorDependencias: No existe

ManejadorDependencias -> BD: 6) INSERT INTO dependencias (req_origen, req_destino)
BD --> ManejadorDependencias: OK
ManejadorDependencias -> ManejadorTrazabilidad: Actualizar matriz
ManejadorTrazabilidad -> BD: UPDATE trazabilidad (nueva relación)
BD --> ManejadorTrazabilidad: OK
ManejadorDependencias -> BD: INSERT auditoria_registroactividad (DEPENDENCIA_CREADA)
BD --> ManejadorDependencias: OK

ManejadorDependencias --> MensajeSistema: 7) "Dependencia creada correctamente"
ManejadorDependencias --> PRelacionarRequerimientos: Refrescar vista

== Alternativos ==
alt 5a) Relación ya existente
  ManejadorDependencias -> BD: SELECT dependencias
  BD --> ManejadorDependencias: Relación encontrada
  ManejadorDependencias --> MensajeSistema: "La relación ya existe"
  note right: El flujo vuelve al paso 3
end

alt 3a) Proyecto sin requerimientos disponibles
  ManejadorDependencias -> BD: SELECT requerimientos
  BD --> ManejadorDependencias: Lista vacía
  ManejadorDependencias --> MensajeSistema: "No hay requerimientos disponibles para relacionar"
  note right: El CU fina
