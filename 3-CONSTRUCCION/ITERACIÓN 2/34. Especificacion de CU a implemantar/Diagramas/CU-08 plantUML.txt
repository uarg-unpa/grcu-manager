@startuml



actor "Usuario (Líder/Dev/Cliente/Admin)" as Usuario #purple
boundary InterfazUsuario
boundary PDetalleRequerimiento
boundary PTabHistorialReq
boundary ModalDetalleHistorialReq
boundary MensajeSistema
control ManejadorRequerimientos
control ManejadorHistorialRequerimiento
control ValidadorPermisos
database BD

== Flujo principal ==
Usuario -> InterfazUsuario: 1) Accede a lista de requerimientos
InterfazUsuario -> PDetalleRequerimiento: 2-3) Selecciona "Ver detalle"
PDetalleRequerimiento -> ManejadorRequerimientos: Cargar datos del requerimiento
ManejadorRequerimientos -> BD: SELECT requerimiento by id
BD --> ManejadorRequerimientos: Datos del requerimiento
ManejadorRequerimientos --> PDetalleRequerimiento: Render con pestañas

Usuario -> PDetalleRequerimiento: 5) Click pestaña "Ver Historial"
PDetalleRequerimiento -> ManejadorHistorialRequerimiento: 6) Traer versiones (history + auditoría)
ManejadorHistorialRequerimiento -> BD: SELECT * FROM historical_requerimiento
ManejadorHistorialRequerimiento -> BD: SELECT * FROM historical_detalle_trad/agil
ManejadorHistorialRequerimiento -> BD: SELECT * FROM auditoria_registroactividad WHERE req_id=...
BD --> ManejadorHistorialRequerimiento: Versiones + auditoría
ManejadorHistorialRequerimiento --> PTabHistorialReq: 7) Línea de tiempo (desc)
PTabHistorialReq --> Usuario: 7) Ver timeline + botón "Ver detalles"

== Ver detalles / comparar ==
Usuario -> PTabHistorialReq: 9) Click "Ver detalles" (una versión)
PTabHistorialReq -> ValidadorPermisos: ¿Puede ver valores antiguos/nuevos?
ValidadorPermisos -> BD: SELECT permisos usuario/proyecto
BD --> ValidadorPermisos: Permitido / Limitado

alt Permiso completo
  PTabHistorialReq -> ManejadorHistorialRequerimiento: Cargar versión (o A/B)
  ManejadorHistorialRequerimiento -> BD: SELECT versión(es)
  BD --> ManejadorHistorialRequerimiento: Datos
  ManejadorHistorialRequerimiento --> ModalDetalleHistorialReq: Tabla "Antes → Después"
  ModalDetalleHistorialReq --> Usuario: 10) Ver comparativa
  Usuario -> PDetalleRequerimiento: 11) Volver al requerimiento
  Usuario -> InterfazUsuario: 12) Volver a la lista (fin)
else Permiso limitado
  PTabHistorialReq --> Usuario: Mostrar resumen sin valores
  PTabHistorialReq -> MensajeSistema: "Permisos limitados"
end

== Alternativos ==
alt 6a) Requerimiento sin historial
  ManejadorHistorialRequerimiento -> BD: SELECT history (count=1)
  BD --> ManejadorHistorialRequerimiento: Solo creación
  ManejadorHistorialRequerimiento --> PTabHistorialReq: "Sin historial de cambios"
  Usuario -> PDetalleRequerimiento: 11) Volver al requerimiento
end

alt 6b) Historial muy extenso (>100)
  PTabHistorialReq -> ManejadorHistorialRequerimiento: Paginación y filtros
  ManejadorHistorialRequerimiento -> BD: SELECT ... LIMIT/OFFSET + filtros
  BD --> ManejadorHistorialRequerimiento: Página de resultados
  ManejadorHistorialRequerimiento --> PTabHistorialReq: Paginación + opción Exportar CSV/PDF
  note right: El CU finaliza tras la exportación o navegación
end

' (Opcional) registrar consulta
PTabHistorialReq -> ManejadorHistorialRequerimiento: Registrar consulta (opcional)
ManejadorHistorialRequerimiento -> BD: INSERT auditoria (CONSULTA_HISTORIAL_REQ)

@enduml
